# S3 Bucket

Utilizes the AWS SDK for Python (Boto3) to export DataCite records as objects in an S3 bucket.

## Credentials

Use a shared credentials file to export records to an S3 bucket.

See [S3 Credentials](../reference/credentials.md) for setup instructions.

## Required Options

- `--endpoint-url` must be assigned to the complete URL to use for the constructed S3 client
- `--bucket` must be assigned to an existing S3 bucket


## `bulk-export` Examples

### Basic
```bash
datacite-websnap bulk-export --client-id ethz.wsl --endpoint-url "https://examplecloud.com" --bucket opendata
```
  - Return all DataCite records for the EnviDat repository (using client-id `ethz.wsl`)
  - Write XML records to a bucket called `opendata`


### Advanced
```bash
datacite-websnap bulk-export --client-id ethz.wsl --endpoint-url "https://examplecloud.com" --bucket opendata --profile-name dev --key-prefix wsl --file-logs
```
  - Specify `dev` as the profile to use in the `~/.aws/credentials` file
  - Use key prefix `wsl`
  - Enable logging to a file


## `doi-export` Examples

### Basic
```bash
datacite-websnap doi-export --doi 10.16904/envidat.518 --endpoint-url "https://examplecloud.com" --bucket opendata
```
  - Export a single DataCite DOI XML record, JSON record, and associated resource data files
  - Write records and data files to a bucket called `opendata`


### Advanced
```bash
datacite-websnap doi-export --doi 10.16904/envidat.518 --endpoint-url "https://examplecloud.com" --bucket opendata --profile-name dev --key-prefix wsl --file-logs
```
  - Specify `dev` as the profile to use in the `~/.aws/credentials` file
  - Use key prefix `wsl`
  - Enable logging to a file
